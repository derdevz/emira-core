# Emira Web App

This app is the public-facing promotional website for the Emira clicker coin hackathon project.

## Purpose

- explain the Emira token story
- present tokenomics in a readable way
- describe the Soroban smart contract angle
- collect early community interest

## Main Tech

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion

## Deployment

The app is configured for GitHub Pages through the repository workflow in `.github/workflows/deploy-pages.yml`.
